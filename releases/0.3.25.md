# Windows on ARM and app-wide lead guidance

> Historical development note only. Installer/update references describe earlier implementation or release targets; they do not provide current download links or prove that artifacts are available from this candidate. Verified VENKY artifacts are not available and automatic updates are disabled here.

## New

- **Windows on ARM (historical release target).** Development metadata included a native `VENKY-Windows-arm64-setup.exe` and updater/`npx` support; this candidate has no verified Windows ARM artifact or download link.
- **One lead guidance for every team.** Settings → Agent teams has a Lead guidance field that applies to every team. A team's own guidance still replaces it for that team, and resetting a team's guidance returns it to the app-wide one. Thanks @ktappdev (#79).

## Fixes

- **The agent team editor is readable again.** The Filter models field is full height, and model names stay visible beside their effort dropdowns. Thanks @ktappdev (#84).

## Known limitations

- The Windows ARM64 build is new and hasn't been tried on a real ARM64 PC yet.
- After app-wide lead guidance is set, an older VENKY Code version can't read the saved team library. Clear the guidance before downgrading.
