# VENKY Code is open source

> Development note, not a published VENKY Code release. This candidate has no verified desktop artifacts or release/download links.


VENKY Code is now free and open source under the VENKY Code License: the MIT
License, plus a requirement that forks used commercially or released publicly
say "This is a fork of VENKY Code" and link back. The code lives at
[github.com/vv3607527-creator/venky-code](https://github.com/vv3607527-creator/venky-code).

- **No license key, no account.** Every feature works as soon as you install. There is nothing to activate or renew.
- **No telemetry.** VENKY Code does not phone home. Your projects and conversations stay on your machine and go only to the coding agents and services you choose. The only automatic requests are anonymous checks for new versions of your installed coding CLIs and a daily public model price list.
- **Updates.** Release checking and downloads are disabled in this candidate until real VENKY artifacts are verified. Do not use legacy PandaCode installers.
- **Build it yourself.** Clone the repository, run `npm ci` and `npm run tauri dev`. CONTRIBUTING.md lists the prerequisites, tests and pull request process.
- **Contribute.** Bug reports and ideas are welcome as GitHub issues, and security problems can be reported privately through GitHub Security Advisories.

Known limitations: release builds are not code-signed yet, so macOS asks you to choose Open Anyway in Privacy & Security the first time, and Windows SmartScreen may warn about an unknown publisher. The in-app update installer is disabled until verified VENKY artifacts are available.
