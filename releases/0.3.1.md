# Automatic updates and a GitHub view

> Historical development note, not a published VENKY Code release. The updater is disabled in this candidate and no verified desktop artifacts are available.


- **Updater support.** Earlier development code checked signed release metadata and downloaded updates. That path is disabled in this candidate until real VENKY artifacts are verified. It restarts to install once no agent is working and you've stepped away, or right away from **Restart to update** in the status bar. Settings → About shows the status, offers Check now, and can turn automatic updates off.
- **GitHub view.** A third view beside Conversation and Board lists your repositories. For each one: its threads, open pull requests and open issues. Review a pull request, fix its checks, address review comments or merge it when ready; solve an issue in one click or open it in a thread. Every thread is linked to its pull request or issue, and repositories that are only on GitHub can be cloned from there.

**Updating:** Release downloads and automatic updates are unavailable in this candidate until real VENKY artifacts are verified.
